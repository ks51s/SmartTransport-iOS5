# SmartTransport для iOS 5

Нативный порт SmartTransport для iPhone / iPod Touch с архитектурой armv7 и iOS 5.0+.

Используется оригинальный публичный Bus62 API для получения данных о городах, остановках, маршрутах, прогнозах и планировании поездок.

## Функции

- Отображение транспорта в реальном времени с обновлением каждые 5 секунд.
- Линии маршрутов, остановки и ближайший транспорт.
- Избранные маршруты и остановки, история поиска.
- Поиск городов и остановок.
- Прогнозы прибытия и планирование поездок.
- Три темы: iOS 6, iOS 7 и тёмная.
- Фильтрация значков остановок.
- Квадратная сетка маршрутов по автобусам, троллейбусам и трамваям с переключателями типов.
- Сохранение текущего набора включённых маршрутов в избранное кнопкой `★`.

Маркеры транспорта анимируются через Core Animation и сохраняются между обновлениями. Цвета транспорта: красный — автобус, оранжевый — маршрутка, голубой — троллейбус, зелёный — трамвай.

После долгого отсутствия на карте транспорт моментально переходит в актуальные позиции без проигрывания накопившейся анимации.

Для производительности на iPhone 3GS/4 значки остановок по умолчанию скрыты. Их можно включить кнопкой рядом с поиском или в настройках карты.

## Подготовка окружения

На Debian/Ubuntu, Arch/Manjaro, Fedora/RHEL, openSUSE, Alpine и Void Linux зависимости, Meow, Theos toolchain и iPhoneOS 6.1 SDK можно подготовить одной командой:

```sh
./prepare.sh
```

Существующий `$HOME/meow` не перезаписывается. Для его обновления используйте `UPDATE_MEOW=1 ./prepare.sh`; тесты Meow можно пропустить через `SKIP_MEOW_TESTS=1`.

Внутри `prepare.sh` Meow автоматически собирается эквивалентом следующих команд:

```sh
git clone https://github.com/sqmrak/meow
cd meow
cargo build --release
```

## Сборка

```sh
./ios6/scripts/build.sh -j 8
```

Готовый файл: `build/SmartTransport.ipa`.
По умолчанию используются Meow из `$HOME/meow/target/release/meow` и iPhoneOS 6.1 SDK из `$HOME/ios6-tooling`. IPA подписан через `ldid`; для установки потребуется jailbreak/AppSync либо повторная подпись.

## Additional information

API используется через HTTP из-за проблем совместимости TLS-сертификатов с iOS 6. Учётные данные пользователей не отправляются.

Уведомлений нет, т.к. требуется Firebase

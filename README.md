# SmartTransport для iOS 5

Порт SmartTransport для iPhone / iPod Touch с архитектурой armv7 и iOS 5-10.

Используется оригинальный публичный Bus62 API для получения данных о городах, остановках, маршрутах, прогнозах и планировании поездок.

## Функции

- Отображение транспорта в реальном времени с обновлением каждые 5 секунд.
- Линии маршрутов, остановки и ближайший транспорт.
- Избранные маршруты и остановки, история поиска.
- Поиск городов и остановок.
- Прогнозы прибытия и планирование поездок.
- Три темы: iOS 6, iOS 7 и тёмная.
- Фильтрация значков остановок.

Цвета транспорта: красный — автобус, оранжевый — маршрутка, голубой — троллейбус, зелёный — трамвай.

## Подготовка окружения

На Debian/Ubuntu, Arch/Manjaro, Fedora/RHEL, openSUSE, Alpine и Void Linux зависимости, Meow, Theos toolchain и iPhoneOS 6.1 SDK можно подготовить одной командой:

```sh
./prepare.sh
```

Существующий `$HOME/meow` не перезаписывается. Для его обновления используйте `UPDATE_MEOW=1 ./prepare.sh`; тесты Meow можно пропустить через `SKIP_MEOW_TESTS=1`.

## Сборка

```sh
./ios6/scripts/build.sh -j 8
```

Готовый файл: `build/SmartTransport.ipa`.
По умолчанию используются meow из `$HOME/meow/target/release/meow` и iPhoneOS 6.1 SDK из `$HOME/ios6-tooling`. IPA подписан через `ldid`; для установки потребуется jailbreak/AppSync либо повторная подпись.
